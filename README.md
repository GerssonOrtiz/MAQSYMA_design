# MAQSYMA - Inversoras de Soldadura ESAB

Experiencia web interactiva *Industrial Cinematic Premium* diseñada para MAQSYMA, distribuidor especializado de tecnología de soldadura ESAB en México.

## Características
- **Hero Cinematográfico**: Secuencia de 500vh controlada por scroll con GSAP ScrollTrigger y canvas físico de chispas en tiempo real.
- **Activos Originales ESAB**: Extraídos fielmente de cartelería técnica y catálogo oficial (Rogue, Rebel, Warrior, HandyArc).
- **Rendimiento y SEO**: Cero dependencias pesadas innecesarias, soporte completo `prefers-reduced-motion` y metadatos OpenGraph.
- **Módulo Comercial**: Cotizador dinámico enlazado a la API oficial de WhatsApp.

## Despliegue en Vercel
Este proyecto es un sitio estático optimizado con `vercel.json` configurado para caché inmutable de assets y encabezados de seguridad.
